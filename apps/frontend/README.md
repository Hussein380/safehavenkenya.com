# Safe Haven Consultancy

Safe Haven Consultancy provides leadership development, mental health awareness, training, and community empowerment programs. Your safe space for growth and healing.

## Project info

This project is a modern web application built for Safe Haven Consultancy to showcase their services and provide resources to the community.

## Getting Started

Follow these steps to run the project locally:

### Prerequisites

- Node.js & npm installed

### Installation

1.  Clone the repository:
    ```bash
    git clone <YOUR_GIT_URL>
    ```

2.  Navigate to the project directory:
    ```bash
    cd safehavenkenya.com/frontend
    ```

3.  Install dependencies:
    ```bash
    npm install
    ```

4.  Start the development server:
    ```bash
    npm run dev
    ```

## Technologies Used

This project is built with:

- **Vite**: Next Generation Frontend Tooling
- **React**: A JavaScript library for building user interfaces
- **TypeScript**: Typed JavaScript at Any Scale
- **Tailwind CSS**: A utility-first CSS framework
- **Shadcn UI**: Re-usable components built using Radix UI and Tailwind CSS
